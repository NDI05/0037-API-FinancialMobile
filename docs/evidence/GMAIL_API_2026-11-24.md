## Perilaku yang diimplementasikan

- **OAuth dari sesi PAM aktif**: `POST /v1/gmail/connect/start` membuat `state` acak 32 byte,
  disimpan sebagai hash (sekali pakai, TTL ≤10 menit, terikat owner+PKCE verifier sealed
  AES-GCM). `GET /v1/gmail/connect/callback` memvalidasi state, menukar code, memverifikasi
  email akun, menyimpan refresh token terenkripsi, memanggil `users.watch`, menjadwalkan
  backfill, lalu redirect `pam://gmail/connected?status=success|error&reason=<safe_code>`
  — replay/expired/mismatch dijawab redirect `state_invalid`/`state_expired`, bukan 500.
- **Satu koneksi aktif per owner**: indeks unik parsial di DB; start kedua → 409,
  `reconnect:true` untuk mengganti akun (koneksi lama di-stop/di-revoke).
- **Scope minimum** `https://www.googleapis.com/auth/gmail.readonly`; status mengembalikan
  email **masked**, scope, `connected_at`, `last_sync_at`, `watch_expires_at`, `sync_state`,
  `last_error_code`. Tidak ada token/kode/email penuh di respons, DB plaintext, atau log.
- **Pub/Sub push**: `POST /v1/internal/gmail/push` memverifikasi JWT OIDC (issuer Google,
  audience `GMAIL_PUSH_AUDIENCE`, service account `GMAIL_PUSH_SERVICE_ACCOUNT`), lalu
  menyimpan event idempoten (`event_key` unik, payload sealed) dan ACK 204 — ACK dikirim
  setelah event durable; duplikat tidak menambah event. Mailbox tak dikenal di-ACK tanpa
  data (anti-enumeration). Owner **hanya** diresolusi dari hash email tersimpan.
- **Backfill 12 bulan bergulir WIB**: job per bulan kalender, bulan berjalan pertama, satu
  bulan per pass, checkpoint per batch yang sudah diakui, maks 5 halaman per tick;
  pesan di luar periode/format diabaikan; dedupe `g:g<hash email>:<messageId>` + fingerprint.
- **Delta via `history.list`**: cursor disimpan terenkripsi; `404/expired` → rescan bulan
  berjalan + cursor baru dari `profile`; retry halaman tidak kehilangan checkpoint.
- **Watch renew/stop**: renew terjadwal sebelum 24 jam; disconnect → stop watch → revoke
  token → hapus kredensial; kegagalan auth → `NEEDS_REAUTH`.
- **Privasi**: raw MIME diproses di memori dan tidak disimpan; PAN/No. Referensi tidak
  pernah disimpan/di-log; parser Livin memprioritaskan nama `Penerima`.
- **Opt-in**: `GMAIL_ENABLED=false` default; mode production divalidasi (client id/secret,
  redirect HTTPS tanpa query, topic, audience, service account).


- 150 fungsi tes di `internal`/`cmd` (13 di `internal/gmail`, 8 khusus Gmail di
  `internal/httpapi`+`internal/store`).
- Tes kunci: replay/expired/mismatch state, PKCE S256, isolasi owner (status Bob tetap
  `disconnected`, disconnect Bob 409), token/email tidak plaintext, JWT push salah 401 &
  tidak membuat event, push benar 204 duplikat → 1 event, mailbox asing ACK tanpa event,
  backfill filter periode + dedupe (replay imported=0), cursor expired recovery, retry
  halaman tanpa kehilangan checkpoint, renew watch terjadwal, parser menolak PAN/referensi.
- Semua tes memakai `FakeProvider`/`FakeExchanger`/`FakePushVerifier`: tanpa jaringan,
  tanpa kredensial nyata, tanpa DB owner.
